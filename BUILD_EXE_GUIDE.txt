================================================================================
REGISTRAR ML AI CHATBOT - BUILD EXECUTABLE (.EXE) GUIDE
================================================================================

This guide will help you convert the Registrar Chatbot into a standalone 
Windows executable (.exe) file using PyInstaller.

================================================================================
PREREQUISITES
================================================================================

1. Windows Operating System (XP SP3 or newer recommended)
2. Python 3.8+ installed (download from python.org)
3. PyInstaller (already in requirements.txt)
4. All dependencies installed

Verify Python installation:
  > python --version
  > pip --version

================================================================================
STEP 1: PREPARE YOUR ENVIRONMENT
================================================================================

1. Navigate to your project directory in Command Prompt:
   > cd C:\path\to\Register_Chatbot

2. Create a virtual environment (recommended):
   > python -m venv venv
   > venv\Scripts\activate

   You should see (venv) before your prompt.

3. Install all dependencies:
   > pip install -r requirements.txt

   This will install:
   - Flask==2.3.2
   - Flask-CORS==4.0.0
   - pywebview==5.0.1
   - PyInstaller==6.1.0
   - scikit-learn==1.3.2
   - numpy==1.24.3

================================================================================
STEP 2: SPEC FILE IS ALREADY PROVIDED
================================================================================

IMPORTANT: We've included a complete spec file: RegistrarChatbot.spec

This file contains ALL necessary hidden imports for scikit-learn and scipy.

The spec file was created to fix the error:
  ModuleNotFoundError: No module named 'scipy._lib.array_api_compat.numpy.fft'

DO NOT modify the spec file unless you know what you're doing.
The included RegistrarChatbot.spec already has all required imports configured.

================================================================================
STEP 3: BUILD THE EXECUTABLE
================================================================================

OPTION A: AUTOMATIC BUILD (Easiest - Recommended)
==================================================

Simply run the included build script from Command Prompt:

  > build_exe.bat

This will:
  1. Verify all dependencies are installed
  2. Clean previous builds
  3. Build the EXE using the correct spec file with all dependencies
  4. Verify the build was successful
  5. Show you where the .exe file is located

OPTION B: MANUAL BUILD (Using provided spec file)
==================================================

Run this command from your project root:

  > pyinstaller RegistrarChatbot.spec

This:
  - Uses the pre-configured spec file with all hidden imports
  - Includes all scipy, sklearn, and numpy modules
  - Fixes the ModuleNotFoundError issue
  - Creates a proper standalone executable


OPTION C: ALTERNATIVE COMMAND (If spec file doesn't work)
==================================================

If you encounter issues, try:

  > pyinstaller --onefile --console --hidden-import=sklearn --hidden-import=scipy --hidden-import=numpy --hidden-import=flask --hidden-import=flask_cors --name RegistrarChatbot app.py

Note: This may create larger file but includes all necessary modules.


RECOMMENDED APPROACH:

Use Option A (build_exe.bat) for easiest results.
All dependencies and hidden imports are already configured.

================================================================================
STEP 4: LOCATE YOUR EXECUTABLE
================================================================================

After PyInstaller finishes, find your .exe file here:

  > your_project_folder\dist\RegistrarChatbot.exe

Copy this .exe to any location you want to use it.

Build artifacts you can delete (optional):
  - build\ folder (temporary files)
  - RegistrarChatbot.spec file (already in build_config.spec)

================================================================================
STEP 5: RUN YOUR EXECUTABLE
================================================================================

Method 1: Double-click the .exe file
  - Double-click: dist\RegistrarChatbot.exe
  - Application will launch in your web browser

Method 2: Run from Command Prompt
  > dist\RegistrarChatbot.exe

Method 3: Create a desktop shortcut
  - Right-click the .exe
  - Create shortcut
  - Place on desktop

================================================================================
ADVANCED: ADD APPLICATION ICON
================================================================================

To add a custom icon to your .exe:

1. Create or obtain a .ico file (icon image)
   Tools: https://convertio.co/png-ico/ (online converter)

2. Place the icon file in your project root:
   > your_project_folder\app.ico

3. Build with icon:
   > pyinstaller --onefile --windowed --icon=app.ico --name RegistrarChatbot app.py

4. Your .exe will now show your custom icon

================================================================================
TROUBLESHOOTING COMMON ISSUES
================================================================================

Issue 1: "ModuleNotFoundError: No module named 'scipy._lib.array_api_compat...'"
Solution (MOST COMMON):
  1. Delete dist\ and build\ folders: rmdir /s /q dist build
  2. Rebuild using the spec file:
     > pyinstaller RegistrarChatbot.spec
  3. Or use the automated build script:
     > build_exe.bat
  4. The spec file includes all necessary hidden imports

Issue 2: "ModuleNotFoundError: No module named 'sklearn'"
Solution:
  1. Verify dependencies: pip show scikit-learn
  2. If missing, install: pip install scikit-learn==1.3.2
  3. Install all requirements: pip install -r requirements.txt
  4. Rebuild using spec file: pyinstaller RegistrarChatbot.spec

Issue 3: ".exe crashes when I click it"
Solution:
  1. Build with console to see error:
     > pyinstaller --onefile --console --name RegistrarChatbot app.py
  2. Or use build script which shows console output:
     > build_exe.bat
  3. Look at error message in console window
  4. Check if it's the scipy/sklearn issue (Issue 1 above)

Issue 4: "Flask app doesn't start / port already in use"
Solution:
  1. Check if port 5000 is available
  2. Change port in app.py:
     - Find: app.run(host='127.0.0.1', port=5000, debug=True)
     - Change to: app.run(host='127.0.0.1', port=5001, debug=True)
  3. Also update script.js:
     - Find: const API_URL = 'http://localhost:5000';
     - Change to: const API_URL = 'http://localhost:5001';
  4. Rebuild executable

Issue 5: "Large .exe file size (500-800 MB)"
Solution:
  This is NORMAL with scikit-learn included. Alternatives:
  
  Option A: Use --onedir to separate binary and supporting files
    > pyinstaller --onedir --console RegistrarChatbot.spec
  
  Option B: Use alternative simpler ML library (replace scikit-learn)
  
  Option C: Accept the large size (no real impact on functionality)

Issue 6: "PyInstaller not found"
Solution:
  1. Install PyInstaller: pip install PyInstaller==6.1.0
  2. Or install all at once: pip install -r requirements.txt
  3. Then rebuild

Issue 7: "Browser doesn't open automatically"
Solution:
  1. The chatbot should open automatically at http://localhost:5000
  2. If not, manually open: http://localhost:5000 in your browser
  3. The .exe console window shows if Flask is running
  4. If "Running on http://127.0.0.1:5000" appears, it's working

Issue 8: "Permission denied when running .exe"
Solution:
  1. Right-click the .exe file
  2. Select "Properties"
  3. Uncheck "Read-only" if checked
  4. Click "Apply" and "OK"
  5. Try running again

Issue 9: "build_exe.bat doesn't work"
Solution:
  1. Open Command Prompt
  2. Navigate to project folder: cd C:\path\to\Register_Chatbot
  3. Verify you're in the right folder (should see build_exe.bat)
  4. Run: build_exe.bat
  5. If not working, try manual build:
     > pyinstaller RegistrarChatbot.spec

DISTRIBUTION & SHARING
================================================================================

To share your .exe with others:

1. Copy the .exe file from dist\ folder

2. Create a simple installer (optional):
   > pip install pyinstaller-hooks-contrib
   > pyinstaller --onefile --windowed --name RegistrarChatbot app.py

3. Share the single .exe file
   - No installation required
   - No Python needed on user's computer
   - Just double-click to run

Recommended file structure for distribution:
  RegistrarChatbot_v1.0/
  ├── RegistrarChatbot.exe
  ├── README.txt (instructions for users)
  └── requirements.txt (optional, for reference)

================================================================================
CREATING A BATCH FILE FOR EASY LAUNCH
================================================================================

Create "LaunchChatbot.bat" in the same folder as .exe:

---START OF LaunchChatbot.bat---

@echo off
echo Starting Registrar Chatbot...
echo.
echo The application is starting on port 5000
echo Opening browser...
timeout /t 2 /nobreak
start http://localhost:5000
RegistrarChatbot.exe

---END OF LaunchChatbot.bat---

Now users can just double-click LaunchChatbot.bat to start everything!
