================================================================================
REGISTRAR ML AI CHATBOT - BUILD EXECUTABLE (.EXE) GUIDE
================================================================================

This guide will help you convert the Registrar Chatbot into a standalone 
Windows executable (.exe) file using PyInstaller.

================================================================================
PREREQUISITES
================================================================================

1. Windows Operating System (XP SP3 or newer recommended)
2. Python 3.8+ installed (download from python.org)
3. PyInstaller (already in requirements.txt)
4. All dependencies installed

Verify Python installation:
  > python --version
  > pip --version

================================================================================
STEP 1: PREPARE YOUR ENVIRONMENT
================================================================================

1. Navigate to your project directory in Command Prompt:
   > cd C:\path\to\Register_Chatbot

2. Create a virtual environment (recommended):
   > python -m venv venv
   > venv\Scripts\activate

   You should see (venv) before your prompt.

3. Install all dependencies:
   > pip install -r requirements.txt

   This will install:
   - Flask==2.3.2
   - Flask-CORS==4.0.0
   - pywebview==5.0.1
   - PyInstaller==6.1.0
   - scikit-learn==1.3.2
   - numpy==1.24.3

================================================================================
STEP 2: CREATE PYINSTALLER CONFIGURATION FILE
================================================================================

Create a file named "build_config.spec" in your project root with this content:

---START OF build_config.spec---

# -*- mode: python ; coding: utf-8 -*-

block_cipher = None

a = Analysis(
    ['app.py'],
    pathex=[],
    binaries=[],
    datas=[
        ('index.html', '.'),
        ('style.css', '.'),
        ('script.js', '.'),
        ('*.py', '.'),
    ],
    hiddenimports=['sklearn.utils._cython_blas', 'sklearn.utils._typedefs'],
    hookspath=[],
    hooksconfig={},
    runtime_hooks=[],
    excludedimports=[],
    win_no_prefer_redirects=False,
    win_private_assemblies=False,
    cipher=block_cipher,
    noarchive=False,
)

pyz = PYZ(a.pure, a.zipped_data, cipher=block_cipher)

exe = EXE(
    pyz,
    a.scripts,
    a.binaries,
    a.zipfiles,
    a.datas,
    [],
    name='RegistrarChatbot',
    debug=False,
    bootloader_ignore_signals=False,
    strip=False,
    upx=True,
    upx_exclude=[],
    runtime_tmpdir=None,
    console=True,
    disable_windowed_traceback=False,
    argv_emulation=False,
    target_arch=None,
    codesign_identity=None,
    entitlements_file=None,
)

---END OF build_config.spec---

================================================================================
STEP 3: BUILD THE EXECUTABLE
================================================================================

Option A: SIMPLE BUILD (Recommended for first-time)
------------------------------------------------------

Run this command in Command Prompt (from project root):

  > pyinstaller --onefile --windowed --name RegistrarChatbot app.py

This creates:
  - Single .exe file
  - No console window
  - Smaller file size


Option B: ADVANCED BUILD (Using config file)
------------------------------------------------------

Run this command:

  > pyinstaller build_config.spec

This uses your custom configuration for more control.


Option C: ONE-FOLDER BUILD (For debugging)
------------------------------------------------------

Run this command:

  > pyinstaller --onedir --windowed --name RegistrarChatbot app.py

This creates:
  - exe with supporting files in folder
  - Easier to debug if issues occur


RECOMMENDED COMMAND:

  > pyinstaller --onefile --windowed --hidden-import=sklearn --hidden-import=numpy --name RegistrarChatbot --icon=app.ico app.py

================================================================================
STEP 4: LOCATE YOUR EXECUTABLE
================================================================================

After PyInstaller finishes, find your .exe file here:

  > your_project_folder\dist\RegistrarChatbot.exe

Copy this .exe to any location you want to use it.

Build artifacts you can delete (optional):
  - build\ folder (temporary files)
  - RegistrarChatbot.spec file (already in build_config.spec)

================================================================================
STEP 5: RUN YOUR EXECUTABLE
================================================================================

Method 1: Double-click the .exe file
  - Double-click: dist\RegistrarChatbot.exe
  - Application will launch in your web browser

Method 2: Run from Command Prompt
  > dist\RegistrarChatbot.exe

Method 3: Create a desktop shortcut
  - Right-click the .exe
  - Create shortcut
  - Place on desktop

================================================================================
ADVANCED: ADD APPLICATION ICON
================================================================================

To add a custom icon to your .exe:

1. Create or obtain a .ico file (icon image)
   Tools: https://convertio.co/png-ico/ (online converter)

2. Place the icon file in your project root:
   > your_project_folder\app.ico

3. Build with icon:
   > pyinstaller --onefile --windowed --icon=app.ico --name RegistrarChatbot app.py

4. Your .exe will now show your custom icon

================================================================================
TROUBLESHOOTING COMMON ISSUES
================================================================================

Issue 1: "ModuleNotFoundError: No module named 'sklearn'"
Solution:
  - Make sure virtual environment is activated
  - Run: pip install scikit-learn numpy
  - Rebuild the executable

Issue 2: "Flask app doesn't start"
Solution:
  - Check if port 5000 is available
  - Edit app.py, change port in app.run(port=5000) to another port
  - Rebuild the executable

Issue 3: ".exe crashes immediately"
Solution:
  - Build with console window to see error:
    pyinstaller --onefile --console --name RegistrarChatbot app.py
  - Check output for error messages
  - Add hidden imports: --hidden-import=sklearn --hidden-import=numpy

Issue 4: "Large .exe file size (500+ MB)"
Solution:
  - This is normal with scikit-learn and numpy included
  - Use --onedir instead of --onefile to reduce .exe size
  - Delete dist\ folder and rebuild

Issue 5: "Port 5000 already in use"
Solution in app.py:
  - Find: app.run(host='127.0.0.1', port=5000, debug=True)
  - Change to: app.run(host='127.0.0.1', port=5001, debug=True)
  - Also update script.js: const API_URL = 'http://localhost:5001';
  - Rebuild executable

Issue 6: "Browser doesn't open automatically"
Solution:
  - Manually open: http://localhost:5000 in your browser
  - .exe is running in background (check console)

DISTRIBUTION & SHARING
================================================================================

To share your .exe with others:

1. Copy the .exe file from dist\ folder

2. Create a simple installer (optional):
   > pip install pyinstaller-hooks-contrib
   > pyinstaller --onefile --windowed --name RegistrarChatbot app.py

3. Share the single .exe file
   - No installation required
   - No Python needed on user's computer
   - Just double-click to run

Recommended file structure for distribution:
  RegistrarChatbot_v1.0/
  ├── RegistrarChatbot.exe
  ├── README.txt (instructions for users)
  └── requirements.txt (optional, for reference)

================================================================================
CREATING A BATCH FILE FOR EASY LAUNCH
================================================================================

Create "LaunchChatbot.bat" in the same folder as .exe:

---START OF LaunchChatbot.bat---

@echo off
echo Starting Registrar Chatbot...
echo.
echo The application is starting on port 5000
echo Opening browser...
timeout /t 2 /nobreak
start http://localhost:5000
RegistrarChatbot.exe

---END OF LaunchChatbot.bat---

Now users can just double-click LaunchChatbot.bat to start everything!
