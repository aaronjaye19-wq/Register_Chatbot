You got this error when clicking RegistrarChatbot.exe:

QUICK FIX (Just 3 steps):
================================================================================

STEP 1: Delete old builds
  Open Command Prompt and type:
  
  > rmdir /s /q dist
  > rmdir /s /q build

  (Just press Y if it asks to confirm)


STEP 2: Run the build script we created
  
  In the same Command Prompt, type:
  
  > build_exe.bat

  Then wait 2-5 minutes while it builds. You'll see lots of text - that's normal!


STEP 3: Test the new .exe
  
  When it finishes, find and double-click:
  
  dist\RegistrarChatbot.exe

  A console window will appear, then your browser should open.
  It should work now!


IF build_exe.bat DOESN'T WORK:
================================================================================

Try the manual rebuild:

  > pyinstaller RegistrarChatbot.spec

Then run:

  > dist\RegistrarChatbot.exe


STILL NOT WORKING?
================================================================================

Follow these diagnostic steps:

1. Verify Python works:
   > python --version
   
   (Should show Python 3.8 or higher)

2. Verify PyInstaller is installed:
   > pip show pyinstaller
   
   (Should show PyInstaller version info)

3. Verify dependencies are installed:
   > pip install -r requirements.txt
   
   (This installs/fixes all needed packages)

4. Try building again:
   > rmdir /s /q dist build
   > pyinstaller RegistrarChatbot.spec

5. Test:
   > dist\RegistrarChatbot.exe


WHAT WENT WRONG?
================================================================================

The original build didn't include all the hidden dependencies that scikit-learn
needs. The spec file (RegistrarChatbot.spec) tells PyInstaller exactly which
modules to include.

We've now provided:
  - RegistrarChatbot.spec (pre-configured spec file)
  - build_exe.bat (automated build script)
  - FIX_SCIPY_ERROR.txt (detailed explanation)

These fix the issue.
