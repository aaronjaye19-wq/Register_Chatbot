================================================================================
TECHNICAL DETAILS (FOR REFERENCE)
================================================================================

Why the Spec File Is Important:

The spec file includes these critical hidden imports:
  - scipy._lib._array_api
  - scipy._lib.array_api_compat.numpy.fft (← THE MISSING ONE)
  - scipy._lib.array_api_compat.numpy.linalg
  - scipy.sparse._base
  - scipy.sparse._sputils

Without these explicitly listed, PyInstaller's auto-detection skips them,
causing the ModuleNotFoundError when you run the .exe.

scikit-learn depends on scipy internally for:
  - Mathematical operations (linear algebra, sparse matrices)
  - Numerical arrays (through numpy)
  - Optimization algorithms

When we use TF-IDF vectorization in the chatbot, sklearn → scipy → numpy
chain gets triggered. If any link is missing, the .exe fails.

The Solution:
  RegistrarChatbot.spec explicitly lists all dependencies, ensuring they're
  all included in the .exe bundle.
